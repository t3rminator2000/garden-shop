ЗАПУСК ИЗ ЭТОГО АРХИВА
   Нужен Node.js версии 20.19 или новее и интернет.
   1. Открыть папку проекта в командной строке
   2. npm install
   3. npm run dev
   4. Открыть адрес, который покажет терминал (обычно http://localhost:5173)
   Сборка готовых файлов: npm run build

ТЕСТОВЫЕ АККАУНТЫ

СТЕК
   Vite, React 19, React Router 6. Базы данных нет.

ДАННЫЕ МАГАЗИНА (методичка, п. 2.4.4)
   Папка public/data: clients.json, products.json, orders.json.
   Заказ ссылается на клиента полем clientId, на товар полем productId.
   При первом открытии сайта файлы заливаются в localStorage.
   Дальше сайт читает и пишет только localStorage, файлы не трогает.
   Правки товаров, заказов и клиентов остаются после перезагрузки.
   Вернуть исходное состояние: админ-панель, кнопка «Сбросить данные».

ЗАПРОСЫ К API
   Вход, регистрация и отправка заказа идут на https://dummyjson.com
   Файлы: src/api/auth.js и src/api/orders.js

ГДЕ ЧТО ЛЕЖИТ
   src/pages      страницы сайта
   src/components повторяющиеся блоки
   src/api        работа с данными и запросы
   src/context    корзина, избранное, сравнение, вход
   src/styles     стили и переменные оформления
   public/data    три файла с данными
   public/images  фотографии товаров
